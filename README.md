# JavaScript Assignments & Capstone

## Files
- `assignment1.js` — Variables, data types, and console operations
- `assignment2.js` — Operators, expressions, and prompt input
- `assignment3.js` — Conditional logic
- `assignment4.js` — Loops and flow control
- `assignment5.js` — Functions and scope
- `assignment6.js` — Arrays, objects, `forEach`, `filter`, and `map`
- `capstone_project.js` — Product inventory and analytics dashboard
- `index.html` — Browser runner for all scripts
- `Output_Screenshots/` — Save your output screenshots here

## How to run
1. Keep `index.html` and all `.js` files in the same folder.
2. Open `index.html` in a modern browser.
3. Press `F12` and open the **Console** tab.
4. Click the button for the assignment you want to run.
5. For Assignment 2, enter `100` and `15` to get the sample bill output.
6. For the Capstone, enter `Monitor` and `150` to get the sample inventory total of `$975`.

You can also open a terminal in this folder and run scripts that do not need browser prompts with Node.js, for example:
`node assignment1.js`

Assignments using `prompt()` require a browser.

## Sample capstone result
- Laptop: $800 — Premium
- Mouse: $25 — Budget
- Monitor: $150 — Standard
- Total inventory value: $975
- Affordable items under $200: `["Mouse","Monitor"]`
